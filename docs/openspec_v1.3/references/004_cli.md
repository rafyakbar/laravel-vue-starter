# OpenSpec CLI Reference

> Source: https://github.com/Fission-AI/OpenSpec/blob/main/docs/cli.md

## Summary

| Category | Commands | Purpose |
|----------|----------|---------|
| Setup | `init`, `update` | Initialize and update OpenSpec |
| Browsing | `list`, `view`, `show` | Explore changes and specs |
| Validation | `validate` | Check for issues |
| Lifecycle | `archive` | Finalize completed changes |
| Workflow | `status`, `instructions`, `templates`, `schemas` | Artifact-driven workflow support |
| Schemas | `schema init/fork/validate/which` | Create and manage custom workflows |
| Config | `config` | View and modify settings |

## Setup Commands

### `openspec init [path] [options]`

Initialize OpenSpec in your project.

Options:
- `--tools <list>` — Configure AI tools (all, none, or comma-separated)
- `--force` — Auto-cleanup legacy files
- `--profile <profile>` — Override global profile (core or custom)

### `openspec update [path]`

Regenerate AI tool config files after upgrading CLI.

## Browsing Commands

### `openspec list [options]`

List changes or specs.

```bash
openspec list            # List active changes
openspec list --specs    # List all specs
openspec list --json     # JSON output
```

### `openspec show [item-name] [options]`

Display details of a change or spec.

```bash
openspec show add-dark-mode
openspec show auth --type spec
openspec show add-dark-mode --json
```

### `openspec view`

Interactive terminal dashboard.

## Validation

### `openspec validate [item-name] [options]`

```bash
openspec validate add-dark-mode    # Validate specific change
openspec validate --all            # Validate everything
openspec validate --specs          # Validate all specs
openspec validate --all --json     # JSON output for CI
```

## Lifecycle

### `openspec archive [change-name] [options]`

```bash
openspec archive add-dark-mode
openspec archive add-dark-mode --yes        # Skip prompts
openspec archive update-ci --skip-specs     # Skip spec updates
```

## Workflow Commands

### `openspec status [options]`

Display artifact completion status.

```bash
openspec status --change add-dark-mode
openspec status --change add-dark-mode --json
```

### `openspec instructions [artifact] [options]`

Get enriched instructions for creating an artifact. Used by AI agents.

```bash
openspec instructions design --change add-dark-mode --json
openspec instructions apply --change add-dark-mode --json
```

### `openspec schemas`

List available workflow schemas.

## Schema Commands

### `openspec schema init <name>`

Create a new project-local schema.

```bash
openspec schema init rapid --description "Fast workflow" --artifacts "proposal,tasks"
```

### `openspec schema fork <source> [name]`

Copy an existing schema to customize.

```bash
openspec schema fork spec-driven my-workflow
```

### `openspec schema validate [name]`

Validate schema structure and templates.

### `openspec schema which [name]`

Show where a schema resolves from (project, user, or package).

## Config Commands

### `openspec config <subcommand>`

```bash
openspec config path           # Show config file location
openspec config list           # Show all settings
openspec config get <key>      # Get specific value
openspec config set <key> <v>  # Set a value
openspec config profile        # Configure workflow profile
openspec config edit           # Open in editor
```

## Environment Variables

| Variable | Purpose |
|----------|---------|
| `OPENSPEC_TELEMETRY` | Set to 0 to disable telemetry |
| `DO_NOT_TRACK` | Set to 1 to disable telemetry |
| `OPENSPEC_CONCURRENCY` | Default concurrency for bulk validation |
