# About Spatie

> Source: https://spatie.be/docs/laravel-permission/v7/about-us

Spatie is a web design agency located in Antwerp, Belgium. They rely on open source software across all of their projects.

This package was originally inspired by Jeffrey Way's Laracasts lessons on implementing permissions and roles in Laravel. Notable contributors include Alex Vanderbist (v2 development) and Chris Brown (longtime maintainer).
