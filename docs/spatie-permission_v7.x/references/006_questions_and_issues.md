# Questions & Issues

> Source: https://spatie.be/docs/laravel-permission/v7/questions-issues

- **General bugs and feature requests** — open an issue on GitHub: [github.com/spatie/laravel-permission/issues](https://github.com/spatie/laravel-permission/issues)
- **Security vulnerabilities** — email the maintainers directly. Do **not** post security issues to the public issue tracker.
